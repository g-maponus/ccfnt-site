Les 3 rencontres annuelles

Rentrée (sept/oct), Chandeleur (février), fin d'année scolaire (mai/juin) — voir /communaute/rencontres/. Le Slug RSVP est l'identifiant utilisé dans le lien /rsvp/?event=… envoyé par courriel : mettez-le à jour chaque année avec la nouvelle occasion.

⚠️ Où est public — utilisé dans les emails/rappels envoyés à toute la communauté (ne jamais y mettre l'adresse complète, juste « chez Untel »). Adresse est privée — envoyée uniquement dans la confirmation RSVP, une fois la réponse approuvée dans l'onglet 🙋 RSVP.

Réponses RSVP

Réponses envoyées depuis les pages /rsvp/?event=… liées dans les courriels. Chaque réponse reçoit d'abord un accusé de réception sans l'adresse ; approuvez une entrée « ⏳ En attente » pour lui envoyer l'adresse (anti-spam / vérification).

⬆️ Import en masse — Email/Tél. PROD

Collez une ligne par personne — Nom, Email PROD, Tél PROD — depuis un tableur (collage direct, colonnes séparées par tabulation) ou un CSV (virgules). Le nom doit correspondre à la colonne Nom ci-dessus (accents/majuscules sans importance). Les cases vides ne remplacent rien ; seules les colonnes PROD sont modifiées.
